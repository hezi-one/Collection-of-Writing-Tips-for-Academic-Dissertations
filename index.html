推荐学习路径

学生可以按“先理解写作，再核对规范，最后提交检查”的顺序使用。

1

先看写作入门

明确论文的研究问题、证据和观点。

2

再看学位规则

确认封面、摘要、目录、正文、参考文献等结构。

3

速查国标细节

核对题名、关键词、图表编号、单位和引用。

4

提交前总检查

用各网页的清单逐项打勾，减少格式扣分。

GitHub Pages 静态部署

把下面四个 HTML 文件放到同一个仓库根目录即可。

推荐目录结构

GitHub Pages 会默认把 index.html 作为首页。

your-repo/ ├─ index.html ├─ academic_paper_guide(1).html ├─ GBT 7713.1—2006thesis_rules_student.html └─ academic_paper_guide_gbt_7713_html.html

在仓库 Settings → Pages 中选择部署分支，例如 main / root，保存后访问 GitHub Pages 给出的链接。
